# LAB 00 — Azure Administration Workstation

## Objective

Build a local Azure administration and cloud security workstation without requiring an active Azure subscription.

This workstation will be used to develop, validate, document, and version-control Azure administration labs throughout this portfolio.

## Environment

### Hardware

- CPU: Intel Core i9-13900H
- RAM: 32 GB
- Architecture: x64


### Operating System

- Windows 11 Home
- WSL2
- Ubuntu 24.04

## Installed Tools

| Tool | Purpose |
|---|---|
| PowerShell 7 | Administration and automation |
| Azure CLI | Azure command-line administration |
| Bicep CLI | Azure Infrastructure as Code |
| Git | Source control |

| Visual Studio Code | Development environment |
